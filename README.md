# Retail Sales Performance Analysis

An entry-level data analysis project using Python, Pandas, SQL, and Matplotlib to turn retail transaction data into business insights.

## Business questions

- Which product categories and regions generate the most revenue?
- How do monthly sales and profit change over time?
- Which customer segments and payment methods are most valuable?
- Where can the business improve performance?

## Tools

Python, Pandas, NumPy, Matplotlib, SQLite, SQL, Jupyter Notebook

## Project workflow

1. Load and validate transaction data.
2. Clean dates, numeric columns, duplicates, and missing values.
3. Create revenue, cost, and profit metrics.
4. Analyze sales by month, category, region, and customer segment.
5. Use SQL queries for grouped analysis and ranking.
6. Visualize trends and communicate recommendations.

## How to run

```bash
pip install -r requirements.txt
python analysis.py
```

The script prints summary tables and saves charts to `outputs/`.

## Portfolio note

This project uses a small synthetic dataset created for portfolio practice. Replace `data/sales.csv` with a larger public dataset before presenting production-scale results.
